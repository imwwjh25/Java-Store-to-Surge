# Java 重写（Override）和重载（Overload）区别

一句话总结：
**重载是同一个类里，方法名相同、参数列表不同；重写是父子类之间，方法签名完全一样，子类覆盖父类方法。**

## 1. 重载（Overload）

- 位置：**同一个类**中
- 方法名：**必须相同**
- 参数列表：**必须不同**（参数个数、类型、顺序）
- 返回值：**无要求，可以不一样**
- 修饰符：无限制
- 和多态关系：**编译期多态（静态绑定）**
- 异常：没有限制

```
public void say(){}
public void say(String name){} // 重载
public void say(int age){}      // 重载
```

## 2. 重写（Override）

- 位置：**子类和父类之间**（继承 / 实现接口）
- 方法名：**必须相同**
- 参数列表：**必须完全相同**
- 返回值：Java5 + 支持**协变返回类型**（子类返回父类返回值的子类）
- 修饰符：**访问权限不能比父类更严格**（父类 protected，子类不能 private）
- 和多态关系：**运行期多态（动态绑定）**
- 异常：不能抛出比父类更宽泛的受检异常

```
class Father{
    public void say(){
        System.out.println("father");
    }
}
class Son extends Father{
    @Override
    public void say(){ // 重写
        System.out.println("son");
    }
}
```

## 3. 对比表格

表格

| 对比项 | 重载 Overload | 重写 Override |
| --- | --- | --- |
| 范围 | 同一个类 | 父子类（继承） |
| 方法名 | 相同 | 相同 |
| 参数列表 | 必须不同 | 必须相同 |
| 返回值 | 随意 | 一般相同，支持协变返回 |
| 权限修饰符 | 任意 | 不能比父类更严格 |
| 绑定时机 | 编译期绑定 | 运行期绑定 |
| 注解 | 不需要`@Override` | 推荐加`@Override`校验 |

## 4. 常见坑

1. 只改返回值，参数不变：**不是重载，编译报错**
2. 子类方法参数写错：不会报错，变成**重载而不是重写**，容易踩坑，所以尽量写`@Override`
3. 静态方法：静态方法可以 “重写” 的假象，其实是隐藏（hide），不属于真正的 Override，静态看引用类型
